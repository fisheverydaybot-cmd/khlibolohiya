# Довідник НАССР · Хлібологія · Пані Піта

Довідник для працівників магазину-пекарні «Хлібологія» (ФОП Моркотун О.П., вул. Раїси Кириченко, 72) і кафетерію «Пані Піта» (ФОП Німченко М.С., вул. Олеся Гончара, 27), м. Полтава: питання-відповіді, пошук, бланки для друку, QR-наклейки і плакат.

## Як змінити текст самостійно (без програміста)

Усе робиться прямо на сайті github.com, з компʼютера або з телефона.

1. Відкрийте репозиторій на github.com і увійдіть у свій акаунт.
2. Відкрийте потрібний файл (див. таблицю нижче).
3. Натисніть олівець ✏️ («Edit this file») угорі справа.
4. Змініть текст.
5. Натисніть зелену кнопку **Commit changes…**, ще раз **Commit changes**.
6. Через 2–3 хвилини сайт оновиться сам. На телефоні оновіть сторінку (іноді треба відкрити двічі).

Якщо щось зламалось — сайт не зміниться, залишиться попередня версія, а GitHub надішле лист «Run failed». Відкрийте файл, поверніть як було (вкладка **History** у файлі показує всі попередні версії) і збережіть ще раз.

| Що змінити | Файл |
| --- | --- |
| Питання і відповіді | `src/content.md` |
| Назви закладів, адреси, ФОП, телефон «кому дзвонити», кольори | `src/settings.json` |
| Бланки (колонки, кількість рядків, назви) | `src/forms.json` |

Сам сайт (сторінка, PDF бланків) GitHub збирає автоматично з цих файлів — окремо нічого завантажувати не треба.

## Як писати питання в `src/content.md`

```
## 2. Яйця                     ← розділ (номер і назва)

### Як обробити яйця? {#yaitsia}   ← питання; у {#...} — коротка адреса латиницею, без пробілів

1. Перший крок.              ← нумерований список
2. Другий крок.

- пункт списку               ← список без номерів
**жирний текст**

| Колонка 1 | Колонка 2 |     ← таблиця
| --- | --- |
| значення | значення |

Бланк: журнал обробки яєць.  ← стає кнопкою «🖨 Журнал обробки яєць»
Документ: інструкція по обробці курячих яєць.
```

- Адресу `{#yaitsia}` після того, як надрукували QR-наклейки, **не міняйте**: наклейка веде саме на неї.
- Щоб у відповіді зʼявилась кнопка бланка, після «Бланк:» напишіть слова з поля `match` цього бланка в `src/forms.json` (наприклад, «журнал охолодження»). Кілька бланків — через крапку з комою.

## `src/settings.json`

- `points` — заклади: `name` (як буде в шапці бланка), `ops` (ФОП; якщо два — буде вибір).
- `askWho` — кому дзвонити, якщо відповіді немає.
- `siteUrl` — адреса сайту (для QR-кодів у попередньому перегляді).
- `qrDefault` — які QR-наклейки відмічені за замовчуванням.

Лапки `"` і коми між рядками обовʼязкові. Після останнього елемента списку коми немає.

## Для технічної довідки

- Зібрати локально: `python3 src/build.py _site`; PDF бланків: `node src/gen_pdf.js _site` (потрібен Playwright).
- Публікація: GitHub Actions (`.github/workflows/deploy.yml`) → GitHub Pages. У налаштуваннях репозиторію: Settings → Pages → Source: **GitHub Actions**.
- QR-генератор: qrcode-generator (Kazuhiko Arase, MIT).

- Іконка і логотип на плакаті: `src/icons/` (icon-192.png, icon-512.png, icon.svg).
